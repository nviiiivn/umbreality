What Is Wired

Umbreality grew by writing modules, not by extending the one loop that runs them — so things arrived finished and dead, and nothing ever said so. This is the count.

Why this page exists

A function only runs if something calls it. temple/scheduler.py is the only heartbeat in this world — anything not reachable from it, from an HTTP route, or from a spark's own turn is dead code that looks exactly like live code. No test fails. No error appears.

That is how the wardens never patrolled, the pilgrimage was never required, apply_reality_shift was never called, sim/strategies.py was never imported, record_daily_prices left the price history empty for the life of the world, and gnu.cycle — which says “safe on a timer” in its own docstring — was never put on one.

research/wiring.py walks the call graph and a git hook refuses any commit that raises the number below. It can go down. It cannot go up.
